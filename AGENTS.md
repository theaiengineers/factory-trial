# Notes for agents

**How changes are made here.** Every change goes in by pull request. Run the tests before you open one: `python3 -m unittest discover -s tests`. Do not review your own change and do not post a review record for it. When the checks are green, ask for an independent review as `docs/REVIEW_STANDARD.md` describes. A new commit after a review needs a new review. Changes to `factory.yml` and the review standard are always high risk, and so is anything in the risk areas `factory.yml` lists. If a check blocks you, say so; do not look for a way round it.
